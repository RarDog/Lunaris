# 🌐 Провайдеры контента

Lunaris объединяет два фундаментальных класса источников: классические **Booru-доски** и современные **архивы авторов (Pawchive)**.

---

## 📋 Список поддерживаемых провайдеров

### 1. 🐾 Pawchive (REST API v1)
Крупнейший агрегатор контента независимых авторов с платных подписочных сервисов:
- **Поддерживаемые сервисы авторов:**
  - `fanbox` (Pixiv Fanbox)
  - `patreon` (Patreon)
  - `fantia` (Fantia)
  - `boosty` (Boosty.to)
  - `subscribestar` (SubscribeStar)
  - `gumroad` (Gumroad)
  - `dlsite` (DLsite)
  - `discord` (Серверы Discord)
- **Возможности в Lunaris:**
  - Просмотр глобальной ленты свежих постов.
  - Персональные карточки авторов с аватаром, баннером, анонсами и ссылками на оригинальные профили.
  - Полноценная авторизация в профиль Pawchive (логин/пароль или Session Cookie).
  - Двусторонняя синхронизация любимых авторов.

### 2. 🌸 Gelbooru
Популярнейшая база аниме-иллюстраций с подробной системой классификации:
- Теги художников, персонажей, авторских прав (copyright), общие описания.
- Высокое разрешение оригиналов.
- Полнотекстовый поиск и рекомендации.

### 3. 🔞 Rule34 & Realbooru
- **Rule34**: Огромное сообщество, поддержка анимированных GIF и видеофайлов WebM/MP4.
- **Realbooru**: Специализируется на косплее, 3D-рендерах и реалистичном контенте.

### 4. 🐺 e621 / e926
Крупнейший архив фурри-, антро- и тематического арта:
- Богатейшая иерархическая система тегов (виды существ, анатомия, стили).
- Полная поддержка `e926` (безопасный режим с фильтром безопасного рейтинга).

---

## 🔄 Как переключаться между провайдерами

1. В верхней панели ленты (**Feed**) нажмите на чип с текущим названием провайдера (например, `Gelbooru`).
2. В появившемся меню выберите желаемый источник.
3. Лента мгновенно перезагрузится с сохранением выбранного режима отображения (Masonry / Сетка / Список).
