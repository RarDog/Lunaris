# 🔍 Умный поиск и теги

Поиск в Lunaris спроектирован для мгновенного отклика и максимальной гибкости в построении сложных запросов.

---

## ⚡ Мгновенные подсказки тегов (0 мс)

- Приложение сохраняет локальный кэш десятков тысяч популярных тегов на вашем устройстве.
- При начале ввода в поисковую строку подсказки появляются **мгновенно (0 мс)** без ожидания ответа сервера.
- Категории тегов подсвечиваются фирменными цветами:
  - 🔴 **Художник / Автор** (`artist`) — красный
  - 🟢 **Персонаж** (`character`) — зеленый
  - 🟣 **Копирайт / Произведение** (`copyright`) — фиолетовый
  - 🔵 **Вид / Существо** (`species`) — синий
  - ⚪ **Общие теги** (`general`) — нейтральный

---

## 🔀 Оператор мультипоиска `and`

Классические Booru-серверы при поиске нескольких тегов (`tag1 tag2`) возвращают только посты, где **присутствуют оба тега одновременно**.

Lunaris поддерживает специальный оператор **`and`**:
```text
genshin_impact and honkai_star_rail
```
**Как это работает:**
1. Приложение одновременно делает независимые запросы по каждому из тегов.
2. Результаты плавно чередуются в единой бесконечной ленте.
3. Вы получаете сбалансированную выборку сразу по нескольким интересующим вас темам.

---

## 🎯 Общие модификаторы в мультипоиске

При составлении сложных запросов модификатор, указанный в конце, автоматически распространяется на все части запроса:
```text
cat and dog anthro
```
Автоматически преобразуется в поиск:
- `cat anthro`
- `dog anthro`

---

## 🎛️ Поисковые фильтры и операторы

Вы можете уточнять выдачу с помощью операторов:

| Фильтр | Назначение | Пример |
|---|---|---|
| `type:video` | Показывать только видеоролики и WebM | `cat type:video` |
| `type:image` | Показывать только статичные изображения | `landscape type:image` |
| `rating:safe` | Только безопасный контент (SFW) | `wallpaper rating:safe` |
| `rating:explicit` | Контент 18+ | `rating:explicit` |
| `score:>50` | Работы с рейтингом выше 50 лайков | `dragon score:>100` |
| `-tag` | Исключить тег из результатов | `solo -comic` |
