# 🚀 Быстрый старт и установка

### 📥 1. Установка на Android

Релизы приложения публикуются на странице **[GitHub Releases](https://github.com/RarDog/Prisma/releases)**.

Начиная с версии **Prisma 3.0**, APK разделены по архитектуре процессора, чтобы уменьшить размер скачиваемого файла:

| Файл APK | Для каких устройств |
|---|---|
| **`app-arm64-v8a-release.apk`** | **Рекомендуется.** 99% современных смартфонов и планшетов (64-битные процессоры ARM). |
| **`app-armeabi-v7a-release.apk`** | Старые 32-битные Android-смартфоны или бюджетные ТВ-приставки. |
| **`app-x86_64-release.apk`** | Эмуляторы Android на ПК (Bluestacks, Android Studio) или планшеты с процессорами Intel/AMD. |

> [!TIP]
> **Умное автообновление:** При проверке обновлений прямо внутри Prisma приложение **самостоятельно определит архитектуру** вашего процессора и автоматически скачает правильный файл!

#### Шаги установки:
1. Скачайте нужный `.apk` файл на устройство.
2. Откройте файл через менеджер файлов и подтвердите установку («Разрешить установку из этого источника»).
3. Запустите **Prisma**.

---

### 🐧 2. Установка на Linux

Prisma распространяется для 64-битных Linux в виде готового автономного архива:

1. Скачайте **`Prisma-v3.0.0-linux-x64.tar.gz`**.
2. Распакуйте архив в любую удобную папку:
   ```bash
   tar -xzf Prisma-v3.0.0-linux-x64.tar.gz -C ~/Prisma
   ```
3. Запустите приложение:
   ```bash
   cd ~/Prisma
   ./lunaris
   ```

*Системные требования Linux:* GTK-3, GLibc 2.31+, поддержка OpenGL/Vulkan для аппаратного ускорения видео.

### 🎨 3. Первый запуск и базовая настройка

После первого запуска рекомендуем заглянуть в раздел **Настройки**:
- **Тема оформления**: 
  - *Системная*: следует за темой устройства.
  - *Светлая / Тёмная*.
  - *AMOLED Pure Black*: истинно черный фон (`#000000`) для экономии заряда на экранах OLED.
  - *Динамические цвета (Material You)*: адаптация акцентных цветов под ваши системные обои Android.
- **Интерфейс**: выбор языка (Русский / Английский).
- **Провайдер по умолчанию**: выберите сервис, лента которого будет открываться первой при старте.
